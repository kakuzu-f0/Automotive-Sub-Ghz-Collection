## 📌 Overview

This repository contains **130+ Sub-GHz key fob captures** from various vehicle manufacturers, organized by region and brand. All signals are optimized for **Flipper Zero** research and testing.

| Region | Brands | Files |
|--------|--------|-------|
| **American** | Chrysler, Dodge, Jeep, Ford, GM (Chevrolet/Buick/Cadillac/GMC), Tesla, Honda | 40+ |
| **Asian** | BYD, Honda, Acura, Hyundai, Kia, Genesis, Lexus, Toyota, Mazda, Nissan, Subaru, Suzuki, Isuzu, LDV | 60+ |
| **European** | Audi, Citroen, FIAT, Groupe PSA, Lamborghini, Mercedes, BMW, Peugeot, Renault, Skoda, Volvo, VW | 30+ |

---

## 📁 File Naming Convention

| Code | Meaning |
|------|---------|
| **l** | Lock |
| **u** | Unlock |
| **rs** | Remote Start |
| **t** | Trunk |
| **p** | Panic |
| **sd** | Side Door (auto sliding) |

**Format:** `Brand_Model_ButtonCodes.sub`  
**Example:** `Toyota_Camry2019_l-u-t-p.sub`
