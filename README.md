## 📁 File Naming Convention

| Code | Meaning |
|------|---------|
| **l** | Lock |
| **u** | Unlock |
| **rs** | Remote Start |
| **t** | Trunk |
| **p** | Panic |
| **sd** | Side Door (auto sliding) |

**Format:** `Brand_Model_ButtonCodes.sub`  
**Example:** `Toyota_Camry2019_l-u-t-p.sub`
