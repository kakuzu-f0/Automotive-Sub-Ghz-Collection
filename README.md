## 📌 Overview

This repository contains **323+ Sub-GHz key fob captures** from various vehicle manufacturers, organized by region and brand. All signals are optimized for **Flipper Zero** research and testing.

## 📁 File Naming Convention

| Code | Meaning |
|------|---------|
| **l** | Lock |
| **u** | Unlock |
| **rs** | Remote Start |
| **t** | Trunk |
| **p** | Panic |
| **sd** | Side Door (auto sliding) |

**Format:** `Brand_Model_ButtonCodes.sub`  
**Example:** `Toyota_Camry2019_l-u-t-p.sub`
